# AWS S3

S3 is used for object storage — listing images, exports, uploaded files, and other binary or JSON payloads.

Implementation lives in `src/lib/aws.ts` alongside the EventBridge client.

## Environment variables

| Variable | Required | Default | Description |
|---|---|---|---|
| `AWS_REGION` | No | `us-east-1` | AWS region |
| `AWS_S3_BUCKET` | Recommended | — | Default bucket name for this service |
| `AWS_ACCESS_KEY_ID` | No | — | Explicit credentials (optional) |
| `AWS_SECRET_ACCESS_KEY` | No | — | Explicit credentials (optional) |
| `AWS_ENDPOINT_URL` | No | — | Custom endpoint (e.g. LocalStack) |

Example:

```env
AWS_REGION=us-east-1
AWS_S3_BUCKET=hoof-public
```

When `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY` are omitted, the AWS SDK uses the [default credential provider chain](https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/setting-credentials-node.html).

When `AWS_ENDPOINT_URL` is set, path-style addressing is enabled automatically (required for LocalStack).

## Client

Get a singleton S3 client:

```typescript
import { getS3Client } from "./lib/aws";

const s3 = getS3Client(env);
```

## Uploading objects

```typescript
import { PutObjectCommand } from "@aws-sdk/client-s3";
import { getS3Client } from "./lib/aws";

const s3 = getS3Client(env);

await s3.send(
  new PutObjectCommand({
    Bucket: env.AWS_S3_BUCKET,
    Key: `listings/${listingId}/metadata.json`,
    Body: JSON.stringify(listing),
    ContentType: "application/json",
  }),
);
```

### Uploading a file buffer

```typescript
import { PutObjectCommand } from "@aws-sdk/client-s3";
import { getS3Client } from "./lib/aws";

await getS3Client(env).send(
  new PutObjectCommand({
    Bucket: env.AWS_S3_BUCKET,
    Key: `listings/${listingId}/cover.jpg`,
    Body: fileBuffer,
    ContentType: "image/jpeg",
  }),
);
```

## Reading objects

```typescript
import { GetObjectCommand } from "@aws-sdk/client-s3";
import { getS3Client } from "./lib/aws";

const response = await getS3Client(env).send(
  new GetObjectCommand({
    Bucket: env.AWS_S3_BUCKET,
    Key: `listings/${listingId}/metadata.json`,
  }),
);

const body = await response.Body?.transformToString();
const listing = JSON.parse(body ?? "{}");
```

## Deleting objects

```typescript
import { DeleteObjectCommand } from "@aws-sdk/client-s3";
import { getS3Client } from "./lib/aws";

await getS3Client(env).send(
  new DeleteObjectCommand({
    Bucket: env.AWS_S3_BUCKET,
    Key: `listings/${listingId}/cover.jpg`,
  }),
);
```

## Key naming conventions

Use a predictable prefix structure:

```
listings/{listingId}/metadata.json
listings/{listingId}/images/{filename}
listings/{listingId}/exports/{timestamp}.csv
users/{userId}/uploads/{filename}
```

Keep keys lowercase, use `/` as a delimiter, and include the resource ID for easy lifecycle management.

## Presigned URLs

For direct frontend uploads or downloads, generate presigned URLs:

```typescript
import { GetObjectCommand, PutObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";
import { getS3Client } from "./lib/aws";

const s3 = getS3Client(env);

// Download URL (expires in 1 hour)
const downloadUrl = await getSignedUrl(
  s3,
  new GetObjectCommand({
    Bucket: env.AWS_S3_BUCKET,
    Key: `listings/${listingId}/cover.jpg`,
  }),
  { expiresIn: 3600 },
);

// Upload URL (expires in 15 minutes)
const uploadUrl = await getSignedUrl(
  s3,
  new PutObjectCommand({
    Bucket: env.AWS_S3_BUCKET,
    Key: `listings/${listingId}/cover.jpg`,
    ContentType: "image/jpeg",
  }),
  { expiresIn: 900 },
);
```

Presigned URLs require `@aws-sdk/s3-request-presigner` (not currently installed — add it when needed).

## Local development with LocalStack

```env
AWS_REGION=us-east-1
AWS_ENDPOINT_URL=http://localhost:4566
AWS_ACCESS_KEY_ID=test
AWS_SECRET_ACCESS_KEY=test
AWS_S3_BUCKET=hoof-public
```

Create the bucket in LocalStack:

```bash
awslocal s3 mb s3://hoof-public
```

## IAM permissions

The service typically needs:

```json
{
  "Effect": "Allow",
  "Action": [
    "s3:GetObject",
    "s3:PutObject",
    "s3:DeleteObject"
  ],
  "Resource": "arn:aws:s3:::hoof-public/*"
}
```

Add `s3:ListBucket` if listing prefixes is required.

## Lifecycle

S3 clients are destroyed during graceful shutdown via `destroyAwsClients()` in `src/server.ts`.
